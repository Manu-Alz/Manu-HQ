# Manu HQ

Mi hub personal: rutina (Plan-73), judo, cambio físico, estiramientos, surf, estilo de vida en Uruguay, estudio, proyectos, pipeline de contenido e ideas. Con mi playlist de Spotify sonando.

## Archivos
- `index.html`: estructura y reproductor
- `styles.css`: diseño
- `app.js`: secciones, datos y lógica. Para cambiar la rutina, editá `ROUTINE`; para cambiar la playlist, editá `PLAYLIST`.

## Datos
Todo se guarda en el navegador (localStorage). Si usás el celu y la compu, usá **Exportar datos** en uno e **Importar** en el otro. Hacé un export de vez en cuando como backup.

## Publicar en GitHub Pages
1. Creá un repo nuevo en GitHub (`Manu-HQ`).
2. Subí `index.html`, `styles.css`, `app.js` y `README.md`.
3. Andá a Settings → Pages → Source: *Deploy from a branch* → `main` / `(root)`.
4. Queda en `https://manu-alz.github.io/Manu-HQ/`.
